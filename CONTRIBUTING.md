# Contributing

Thanks for improving Regul8 MCP.

1. Fork the repository and create a branch from `main`.
2. Run `npm install` and `npm run build`; fix any TypeScript errors.
3. Do not commit `.env`, credentials, or `dist/` (build artifacts stay local unless project policy changes).
4. Open a pull request with a short description of the change and how you tested it.

For security-sensitive issues, open a private advisory on GitHub instead of a public issue when appropriate.
